# Como Contribuir

Obrigado pelo interesse em contribuir com a Calculadora Simplex Gráfica!

---

## Reportando bugs

1. Verifique se o bug já foi reportado nas [Issues](https://github.com/kiareli03/simplex-calculator/issues).
2. Se não encontrar, abra uma nova issue com:
   - Descrição clara do problema
   - Passos para reproduzir
   - Comportamento esperado vs. o que aconteceu
   - Navegador e versão utilizados

---

## Sugerindo melhorias

Abra uma issue com o título começando em `[Sugestão]` e descreva:
- O que você gostaria que fosse adicionado ou alterado
- Por que seria útil
- Como você imagina que funcionaria

---

## Enviando código (Pull Request)

1. Faça um fork do repositório
2. Crie uma branch com um nome descritivo:
   ```bash
   git checkout -b minha-melhoria
   ```
3. Faça as alterações e commit:
   ```bash
   git commit -m "Descrição clara do que foi feito"
   ```
4. Envie para o seu fork:
   ```bash
   git push origin minha-melhoria
   ```
5. Abra um Pull Request para a branch `main` deste repositório

---

## Diretrizes de código

- Mantenha o projeto sem dependências externas (HTML, CSS e JS puro)
- Comentários devem ser escritos em português
- Siga o estilo visual existente (tema escuro, mesma paleta de cores)
- Teste no navegador antes de abrir o PR

---

## Dúvidas?

Abra uma issue com o título `[Dúvida]` e responderei assim que possível.
